# TaintForge-IoT

Reverse-Assisted Hybrid Fuzzing with Taint-Guided Minimal Environment Modeling for IoT Malware Analysis

TaintForge-IoT is a research-oriented pipeline for analyzing packed Linux-based IoT malware and enabling automated vulnerability discovery without relying on full firmware emulation.

The project combines dynamic taint analysis, minimal environment reconstruction, QEMU-based execution, coverage-guided fuzzing, and selective symbolic execution into a single modular workflow. Its main goal is to bridge the gap between unpacking IoT malware samples and actually running them in a controlled environment suitable for fuzzing and protocol analysis.
